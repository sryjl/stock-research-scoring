# A股股票观察价位管理工具

一个轻量、直观的个人股票观察与买入计划管理工具。**不是**量化交易软件，也不做自动交易，只把下面这条闭环做好：

> 观察股票 → 观察价 → 三档买入 → 实际成交 → 每笔独立 +5%/+10% → 长持标签 → 状态管理

## 技术方案

- 纯 Python 标准库（`http.server` + `sqlite3` + `unittest`），**零第三方依赖**，无需 `pip install`
- 数据落盘到 SQLite，重启不丢失
- 前端为无框架的单页应用（原生 HTML / CSS / JS），桌面端优先
- 仅监听 `127.0.0.1`，本机使用

## 运行方式

### 方式一：双击 `run.bat`（Windows 推荐）

双击后会启动服务并自动打开浏览器 `http://127.0.0.1:8765`。

### 方式二：命令行

```bash
# 推荐（Windows 的 Python 启动器）
py app.py

# 或直接
python app.py

# 自定义端口
python app.py --port 9000
```

启动后浏览器访问 <http://127.0.0.1:8765>，按 `Ctrl+C` 停止。

> 若提示找不到 Python，请安装 Python 3.8+，或直接指定完整路径，例如：
> `C:\Users\你的用户名\AppData\Local\Programs\Python\Python313\python.exe app.py`

## 运行测试

```bash
python -m unittest discover -s tests
```

测试覆盖：三档观察价始终相对最初基准价、每笔 +5%/+10% 按各自实际成交价计算、
修改观察价只重算未成交计划（不污染已成交 Lot）、数据重启持久化等核心规则。

## 关键业务规则（已实现并测试）

1. **三档观察价** = `P`、`P × 0.95`、`P × 0.90`，全部相对**最初的观察基准价 P** 计算，绝不链式。
2. **三笔买入计划**：每笔都是独立 Lot，计划价与实际成交价分开保存。
3. **每笔独立止盈**：只有在填写实际成交价后，才按该笔成交价计算 `+5%` / `+10%` 目标价，
   与其他笔、与整体平均成本无关。
4. **修改观察价**：只重算「尚未成交」的 Lot 计划价；已成交 Lot 的价格、数量、日期、
   止盈、卖出记录全部冻结不变。
5. **长持型股票**：不生成三笔买入计划，只记录当前价 / 观察价 / 标签 / 备注。
6. **价格精度**：内部保留完整精度（如 9.50 × 1.05 = 9.975），仅在展示时四舍五入（HALF_UP）。
7. **止盈提示**：更新当前价后，已成交 Lot 若达到 +5% / +10% 会显示提示（只提醒，不自动交易）。

## 实时行情

- 数据源：腾讯免费行情（`qt.gtimg.cn`），无需鉴权。
- 顶部「↻ 刷新行情」按钮：手动拉取所有股票的实时当前价。
- 「交易时段自动刷新」：勾选后每 60 秒自动拉取一次，**仅在 A 股开盘时段**
  （工作日 9:30–11:30、13:00–15:00）联网，休市自动跳过、不请求外部接口。
- 第一版用「工作日 + 时段」近似，不含法定节假日日历。
- 拉取失败（断网等）会给出提示，不影响本地已保存数据；也可在详情页手动覆盖当前价。

## 卖出、盈亏与提醒

- **每笔卖出目标**：买入成交后自动算 `卖出目标 = 买入价 × 1.05`，表格里直接显示「买 X / 卖 Y」。
- **计划价可调**：未触发的笔自动按 `P / P×0.95 / P×0.90` 填好计划买入价，可手动改；改观察价不会覆盖手动改过的计划价。
- **卖出归档**：填卖出记录时自动带上成本价；全部卖出后该笔自动归档（重置为空白、保留计划价），历史卖出记录继续保留供复盘。
- **盈亏**：已实现盈利（卖出-买入）×数量、未实现浮盈（现价-买入）×剩余数量，按每笔/每只/全部汇总显示。
- **Windows 提醒**：交易时段内每 60 秒检查一次，价格进入卖出目标 ±1% 范围时弹 Windows 气泡通知（仅提醒，不自动交易）。
- **日期自动补**：填买入/卖出时日期默认当天，无需手选。

## 数据与重置

- 数据库文件：`data/stocks.db`
- 想清空所有数据重新开始：关闭程序后删除 `data/stocks.db`，再次运行会自动重建并写入示例数据。

## 标签

标签可自由添加：在添加/编辑股票的标签输入框里用逗号分隔即可，或在列表「标签」区点选。
默认已内置：`烟蒂`、`长持`、`红利`、`核心仓`、`周期`、`观察`。
